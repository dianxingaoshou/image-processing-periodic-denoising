## 复现

使用本地数据和锁定依赖，从项目根目录运行下面两条命令。首次命令在新目录记录源码、配置、历史档案和实验协议的 SHA-256 指纹。

```text
python evaluate_narrow83.py freeze --out results/narrow83_reproduction
python evaluate_narrow83.py run --out results/narrow83_reproduction
```

逐条件整图与区域质量见 metrics.csv，独立的强度对照见 parity.csv，运行环境及分组统计见 run.json。
