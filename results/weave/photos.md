# 四张新纹理照片的配对检查

在推理源码和参数冻结之后，从 DTD 官方 `test1` 名单的 knitted、woven 两类中分别抽取两张此前未使用的照片。抽样前剔除已有照片，按文件名排序，使用种子 20261118 无放回抽样。先写入名单，再从牛津大学 DTD 官方源下载这四张 JPEG。四个文件均成功获取；评估时沿用 256×256 灰度预处理。该检查独立于此前的 92 个输入。[预选记录](photos_selection.json) · [原图来源、执行与哈希](photos_run.json)

每张照片比较无新增干扰、同一张照片加定频或渐变干扰三种条件；两个加噪条件的生成幅度均为 0.12。原图作为配对参考。下表为整图 MSE，越低越好，括号内为输入 MSE。

| 照片 | 无新增干扰（输入 0），旧→新 | 定频，旧→新（输入） | 渐变，旧→新（输入） |
|---|---:|---:|---:|
| knitted_0103 | 0 → 0 | 0.001113 → 0.001113（0.006889） | 0.002251 → 0.002251（0.004824） |
| knitted_0140 | 0 → 0 | 0.002095 → 0.002095（0.007179） | 0.005016 → 0.005016（0.005016） |
| woven_0079 | 0.014065 → 0 | 0.013667 → 0.002663（0.005329） | 0.013499 → 0.001728（0.003732） |
| woven_0083 | 0.000182 → 0.000182 | 0.007230 → 0.007230（0.007047） | 0.004931 → 0.004931（0.004931） |

四张原图中，误改由 2 张降至 1 张。8 个加噪输入中，相对含噪输入有净改善的由 3 个增至 5 个，原有 3 个净改善的恢复数组逐值保留。3 个新旧数组不同的输入均来自 woven_0079：原图恢复为逐像素保留；加定频和渐变后，新版分别降低约 50.0% 和 53.7% 的输入 MSE。其余 9 个新旧结果逐值一致。样本量为每类两张新照片，同一照片的三个版本属于配对观测。

woven_0083 原图仍因窄条路径被修改，MAE 为 0.001519。加定频后仍走窄条路径，恢复 MSE 高于输入；加渐变后因空间支撑不足而保留输入。此次的格点保护检查位于通用路径，因此没有处理这张照片的窄条误改。knitted_0140 的渐变干扰亦未被处理。[逐图 MSE、MAE、路径及输出哈希](photos_metrics.csv)
